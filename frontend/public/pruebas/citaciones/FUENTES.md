# Citaciones de prueba (fuentes públicas)

Textos de ensayo para TribunalInclusivo. Datos personales **ficticios/anonimizados**.
La estructura y el lenguaje siguen modelos públicos españoles:

1. **COET** — *Cédula de citación para juicios rápidos por delito*  
   http://coet.es/web/images/Categorias/JUICIOS_RAPIDOS/Documentos/Atestados_Diligencias_JR/Atestado%20I/Coet_Citacion_JR_Por_Delito.pdf
2. **Ministerio de Justicia** — modelo de cédula en Lectura Fácil (repositorio justicia accesible).
3. **Aula Judicial (Universidad de León)** — cédula de citación publicada con fines docentes (2011)  
   http://aulajudicial.blogspot.com/2011/01/juicio-de-5-de-derecho-curso-2010-2011_1681.html

No son notificaciones de causas reales de personas vivas; son formularios rellenados para demo y tests.
