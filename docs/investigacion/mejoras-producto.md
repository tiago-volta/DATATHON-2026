# Mejoras de Producto InclusiveCourt: Mapeadas a Pantallas

> Investigación para InclusiveCourt | DATAthon Justicia 2026 | Octubre 2026

- **P1**: Importante, añade valor al pitch
- **P2**: Deseable, si hay tiempo

## 1. Pantalla: Citación (`/citacion`)

**Función actual**: Procesar una citación judicial y explicarla en lenguaje accesible.

### Mejoras P0

| ID | Mejora | Justificación |
|----|--------|---------------|
| C01 | Pictogramas ARASAAC en cada fase | La investigación confirma que los pictogramas mejoran comprensión en DI y TEA |
| C02 | Audio de la citación explicada | Juan (ceguera) necesita toda la información en audio |
| C03 | Destacar fecha, hora, lugar con iconos | Personas con TDAH pierden detalles clave |

### Mejoras P1

| ID | Mejora | Justificación |
|----|--------|---------------|
| C04 | Temporizador visual de cuenta atrás | Ayuda a personas con TDAH a planificar |
| C05 | Opción de añadir al calendario (ICS) | Recordatorio automático, reduce ansiedad |
| C06 | Versión "super simple" (lectura fácil nivel 1) | Para DI con mayores necesidades de apoyo |
| C07 | Explicar qué pasa si no voy | Frecuente fuente de ansiedad; debe ser claro |

### Mejoras P2

| ID | Mejora | Justificación |
|----|--------|---------------|
| C08 | Carrusel de fotos del juzgado | Anticipación del entorno (TEA) |
| C09 | Mapa interactivo accesible | Orientación previa para ceguera y TEA |

## 2. Pantalla: Pasaporte de Ajustes (`/pasaporte`, `/pasaporte/ver`)

**Función actual**: Crear un perfil de ajustes sin revelar diagnóstico.

### Mejoras P0

| ID | Mejora | Justificación |
|----|--------|---------------|
| P01 | Añadir base legal a cada ajuste | Refuerza la petición; la investigación muestra que los ajustes tienen respaldo legal concreto |
| P02 | Versión exportable en PDF | Para presentar en juzgado |
| P03 | Incluir ajustes para ceguera | Juan necesita: audio, descripción, orientación |

### Mejoras P1

| ID | Mejora | Justificación |
|----|--------|---------------|
| P04 | Selector de intensidad por ajuste | No todos los ajustes se necesitan igual de fuerte |
| P05 | Campo de texto libre para "Otros" | Cada persona puede tener necesidades únicas |
| P06 | Formato compatible con Perfil CGPJ | Alinear con estándar oficial que viene |
| P07 | Envío directo al juzgado (si hay integración) | Reducir fricción |

### Mejoras P2

| ID | Mejora | Justificación |
|----|--------|---------------|
| P08 | QR para acceso rápido | El acompañante puede escanear y mostrar |
| P09 | Tradución a lectura fácil del propio pasaporte | Coherencia: el pasaporte también debe ser accesible |

## 3. Pantalla: Ensaya (`/ensaya`)

**Función actual**: Simulador de declaración con IA.

### Mejoras P0

| ID | Mejora | Justificación |
|----|--------|---------------|
| E01 | Modo audio completo (voz a voz) | Esencial para Juan; mejora también para dislexia |
| E02 | Feedback sobre respuestas impulsivas | TDAH: "Tomaste X segundos, ¿seguro de tu respuesta?" |
| E03 | Anticipar las preguntas posibles | TEA necesita saber qué le van a preguntar |

### Mejoras P1

| ID | Mejora | Justificación |
|----|--------|---------------|
| E04 | Pausas automáticas cada N preguntas | TDAH: gestión de fatiga atencional |
| E05 | Indicador visual de progreso | Reduce ansiedad de "¿cuánto falta?" |
| E06 | Opción de velocidad de voz | Adaptarse al ritmo de cada persona |
| E07 | Explicar formato de preguntas (abiertas vs cerradas) | TEA: mejor rendimiento con preguntas específicas |

### Mejoras P2

| ID | Mejora | Justificación |
|----|--------|---------------|
| E08 | Escenarios personalizados por tipo de caso | Testigo ≠ investigado |
| E09 | Gamificación con puntos de calma | Refuerzo positivo por gestión emocional |

## 4. Pantalla: Sala Previa (`/sala-previa`)

**Función actual**: Vista 360° del juzgado para anticipación.

### Mejoras P0

| ID | Mejora | Justificación |
|----|--------|---------------|
| S01 | Audiodescripción de la sala | Juan no puede ver el 360°; necesita descripción |
| S02 | Etiquetas en roles (juez, fiscal, etc.) | TEA: identificar quién es quién |
| S03 | Navegación por teclado | Accesibilidad técnica básica |

### Mejoras P1

| ID | Mejora | Justificación |
|----|--------|---------------|
| S04 | Secuencia guiada: "primero entras aquí, luego..." | TEA: necesita la secuencia exacta |
| S05 | Señalar zonas de espera y baños | Orientación práctica |
| S06 | Modo "tranquilo" (sin animaciones) | Hipersensibilidad sensorial |

### Mejoras P2

| ID | Mejora | Justificación |
|----|--------|---------------|
| S07 | Realidad virtual si hay visor | Inmersión más realista |
| S08 | Fotos reales de juzgados gallegos | Anticipación real, no genérica |

## 6. Pantalla: Mediador / Pregunta Clara (`/mediador`)

**Función actual**: IA que responde dudas sobre el proceso.

### Mejoras P0

| ID | Mejora | Justificación |
|----|--------|---------------|
| M01 | Modo voz (speech-to-text + text-to-speech) | Accesibilidad para ceguera y dislexia |
| M02 | Respuestas en lectura fácil siempre | Coherencia con el resto de la app |

### Mejoras P1

| ID | Mejora | Justificación |
|----|--------|---------------|
| M03 | Preguntas frecuentes predefinidas | Reducir escritura, acelerar acceso |
| M04 | Pictogramas en respuestas clave | Refuerzo visual |
| M05 | Derivación a recursos humanos | Si la duda requiere profesional real |

### Mejoras P2

| ID | Mejora | Justificación |
|----|--------|---------------|
| M06 | Historial de conversaciones | No repetir preguntas |
| M07 | Detectar nivel de ansiedad y adaptar tono | IA empática |

## Notas para el pitch

1. **Mostrar el Pasaporte como entregable tangible**: PDF que la persona lleva al juzgado
2. **Demostrar accesibilidad en vivo**: navegación por voz, lector de pantalla
3. **Conectar cada función con artículo legal**: refuerza viabilidad
4. **Usar a Luis y Juan como hilo narrativo**: humaniza la tecnología
5. **Destacar que NO revela diagnóstico**: resuelve problema real de estigma
